CodeGraph⚔️MemPalace

预索引代码知识图谱 vs 本地优先 AI 记忆系统 —— 一场"关公战秦琼"式对比,以及为什么它俩其实该坐一桌

⚡ 核心结论(先看这个)

这不是竞品对比,是互补关系。CodeGraph 解决"AI Agent 看不懂代码库"的问题(静态代码智能,管空间),MemPalace 解决"AI Agent 记不住对话"的问题(动态记忆,管时间)。两者都是 MIT 协议、100% 本地运行、通过 MCP 协议接入同一批 AI 编程工具,可以同时安装、互不冲突。

真正需要对比的是:数据健康度、架构设计、基准证据质量、以及两个都很年轻的项目各自的风险。

🎯 定位:解决什么问题

CodeGraph —— 代码的地图

痛点:AI 编程 Agent 理解大代码库时,靠 grep/glob/Read 逐文件瞎翻,烧 token、慢、还经常找错地方。

方案:预先用 tree-sitter 把整个代码库解析成知识图谱(符号 + 调用/继承/导入边),存进本地 SQLite。Agent 一次 MCP 调用就拿到精确上下文:入口点、相关符号、代码片段、影响半径。

一句话:让 Agent "查地图"而不是"挨家挨户敲门"。

MemPalace —— 对话的档案柜

痛点:AI Agent 会话结束就失忆(Claude Code 会话 30 天还会过期),跨会话协作等于每天重新认识一遍。

方案:逐字(verbatim)存储原始对话,不做摘要改写;按"记忆宫殿"层级组织(Wings→Rooms→Closets→Drawers),向量检索 + 时序知识图谱召回。

一句话:让 Agent "查档案"而不是"凭印象瞎编"。

📈 性能与基准:证据质量评估

CodeGraph 的牌

  • 7 个真实开源仓库实测(VS Code / Django / Tokio / Alamofire 等):平均 60% 成本↓、69% token↓、89% 工具调用↓,文件读取次数降为 0
  • 索引速度:Swift 编译器仓库(27k 文件)≈100 秒;Linux 内核(70k 文件、200 万符号)12 分钟
  • 日常保存级增量同步 ~0.3-0.4s

评估:数据具体、场景真实,但基准绑定特定模型(Claude Opus 4.8),且为作者自测,未见第三方复现。

MemPalace 的牌

  • LongMemEval(学术基准,500 题):零 API 纯语义 R@5 96.6%,Hybrid v4 98.4%,+ LLM rerank ≥99%
  • LoCoMo R@10 88.9%、ConvoMem 92.9%、MemBench(ACL 2025)R@5 80.3%
  • 诚实性声明:明确拒绝展示"100%"数字(认为那是 teaching to the test),拒绝对 Mem0/Zep 等做不对等横向对比,逐题结果文件全部提交在仓库可复现

评估:用公开学术基准 + 结果文件入库 + 主动声明局限性,证据规范度明显更高。

⚠️ 风险雷达

两家共同的:都是 2026 年才出生的项目(6 个月 / 4 个月),star 却冲到 5.7-6.3 万——这个量级通常是多年积累的结果。增长是自然爆红还是营销/刷量驱动,建议看 star 增长曲线再下结论。生产环境采用请锁版本。
MemPalace fork 比异常:fork/star 达 12.9%(7,438 forks),工具型 repo 常见区间是 5-8%。可能是大量用户自行部署二开,也不排除水分。另外其 README 专门警告"有假冒官网"——被仿冒者盯上,侧面说明热度,但也提醒认准 github.com/MemPalace/mempalace 和 PyPI 官方包。
Bus factor ≈ 1:CodeGraph 是个人项目(colbymchenry);MemPalace 虽是组织账号,但提交高度集中在 igorls 一人。核心作者一旦停更,社区接手能力未知。
Issue 积压:362 / 654 个 open issues,对年轻项目不算灾难,但说明用户涌入速度超过了维护带宽。
值得肯定:两家都是 MIT + 100% 本地运行 + 无 API key 依赖,隐私姿态一致且诚实;MemPalace 的基准诚实性声明、CodeGraph 的逐仓库具体数字,都比"AI 时代平均营销水准"高出一截。

🧭 选型建议

「AI 写代码时瞎翻文件,token 烧得我心疼」

→ 装 CodeGraph。预索引图谱就是干这个的,尤其大仓库(万级文件)收益最大。

「AI 每次都失忆,上周聊的架构决策这周全忘了」

→ 装 MemPalace。逐字记忆 + 自动保存钩子,Claude Code 用户尤其需要(30 天会话过期)。

「我全都要?」

→ 可以,而且是推荐姿势。两者都是 MCP server,一个给 Agent 装"代码地图",一个装"长期记忆",能力正交不打架。Agent 配置里同时挂两个 MCP 即可。

「企业要上车?」

→ 先在小团队试点、锁定版本、观察 3-6 个月。项目太年轻,API 和存储格式都可能变。
