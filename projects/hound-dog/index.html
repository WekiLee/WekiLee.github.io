hound-dog

数据根因分析与报告复核 Skill

活跃开发中
GitHub 返回首页

Overview

概述

hound-dog 是一个通用 agent skill：手里只有一批原始数据（服务台工单、运行日志、业务 Excel/CSV），要回答"问题出在哪、怎么改"时，它把流程从目标对齐、数据画像、维度穷举、交叉验证、复检纠错，推进到根因提炼与可落地建议，让每个结论都能从原始数据逐条溯源、可重跑复现。

Architecture

架构设计

按 P0~P7 八阶段推进，每阶段有明确产出与过关条件，阶段间带反馈回路，关键指标必须 ≥2 个独立口径交叉验证。

对齐与画像

P0 目标对齐P1 数据画像脏数据自动告警

分析与验证

P2 维度穷举P3 交叉验证P4 复检纠错

结论与建议

P5 结论落实P6 根因提炼P7 可落地建议

输出层

MD 分析报告PPT 汇报（可选）可复现档案

Features

核心特性

🔬

先画像后结论

数据画像脚本自动告警重复行、撞名列、字段黑洞，避免被脏数据带偏。

🧾

每个数字可溯源

分析脚本 + 中间产物 + 任务日志串成可复现档案，结论与数据可对账。

🤖

多 agent 可用

一条 npx 命令安装到 Codex / Claude Code / Cursor 等十余种 agent 的 skills 目录。
